# CustomDeathMessages Config ES v1.0

Configuración personalizada en español para **CustomDeathMessages (CDM)**, diseñada para mejorar los mensajes de muerte tradicionales de Minecraft mediante textos más claros, variados y visualmente atractivos.

Esta versión adapta los mensajes al español y mantiene un formato uniforme para que las muertes de los jugadores sean más fáciles de identificar dentro del chat.

La configuración incluye diferentes causas de muerte y conserva información importante como el nombre del jugador, la criatura involucrada o la situación que provocó la muerte.

- Configuración completamente adaptada al español.
- Mensajes de muerte personalizados.
- Diferentes textos según la causa de muerte.
- Formato visual mediante colores.
- Identificación clara del jugador fallecido.
- Mensajes para diferentes criaturas y situaciones.

---

## Instalación

1. Instala **CustomDeathMessages (CDM)** en tu servidor.
2. Inicia el servidor una vez para generar los archivos del plugin.
3. Detén el servidor.
4. Sustituye los archivos correspondientes por los incluidos en esta configuración.
5. Inicia nuevamente el servidor.
6. Prueba diferentes causas de muerte para comprobar los mensajes personalizados.

---

## Dependencia

Esta configuración **no incluye el plugin CustomDeathMessages**.

Es necesario instalar previamente el plugin original:
